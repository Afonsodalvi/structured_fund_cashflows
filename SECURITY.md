# Security policy

This is an unreleased reference candidate with no production deployment supplied by this repository. Review [the threat model and remaining assumptions](docs/SECURITY.md) before integration. Automated testing and static analysis are finite checks, not independent audit or formal proof.

For a sensitive issue, use GitHub's private vulnerability reporting if the future repository owner enables it. If unavailable, arrange a private channel with the maintainer before sending exploit details. No private email address or security service is assumed to exist. Ordinary non-sensitive specification issues can use repository issues or the eventual public discussion.
